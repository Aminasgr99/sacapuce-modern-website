# Sacapuce - Site E-commerce Modernisé 🚀

## Description
Refonte complète et modernisée du site Sacapuce, boutique spécialisée dans les chaussures grandes tailles (40-48).

## 🎨 Caractéristiques

### Design Moderne
- **Palette de couleurs premium** : Noir (#1a1a1a), Or (#d4af37), Rose (#e94b9d)
- **Navigation fluide** et intuitive
- **Responsive design** : Adapté à tous les appareils
- **Animations subtiles** et agréables

### Sections Principales
1. **Navigation sticky** avec search et panier
2. **Hero section** percutant avec CTA
3. **Trust section** - Points forts (depuis 1980, +400 modèles, etc.)
4. **Collections** - 6 catégories principales
5. **Produits** - Grille avec filtres et avis clients
6. **Paiements** - Moyens de paiement variés
7. **Blog** - Conseils et tendances
8. **Footer** - Complet avec liens utiles

### Fonctionnalités
- ✅ Gestion du panier
- ✅ Recherche produits
- ✅ Filtres (taille, prix, tri)
- ✅ Affichage des avis clients
- ✅ Badges (Nouveau, Promo)
- ✅ Animations au scroll

## 📱 Responsive
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (< 768px)
- Ultra-mobile (< 480px)

## 🛠️ Technologies
- **HTML5** sémantique
- **CSS3** moderne (Flexbox, Grid, Variables)
- **JavaScript vanilla** (Intersection Observer, Event Listeners)
- **Font Awesome** pour les icônes
- **Google Fonts** (Poppins)

## 🚀 Utilisation

### Installation
```bash
# Cloner le repository
git clone https://github.com/Aminasgr99/sacapuce-modern-website.git

# Accéder au dossier
cd sacapuce-modern-website

# Ouvrir index.html dans le navigateur
open index.html
```

### Structure des fichiers
```
.
├── index.html      # Page principale
├── styles.css      # Styles CSS
├── script.js       # Logique JavaScript
└── README.md       # Documentation
```
